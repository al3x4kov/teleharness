# git-changes Specification

## Purpose
Изменения хода и git в интерфейсе: строка «Изменения» под ответом с диффом каждого файла, экран Git папки чата или проекта (статус, коммит выбранных файлов, сообщение от модели чата, отправка для администратора) и раздел «Git» в Настройках. Обычный пользователь — только в своих папках, без отправки и смены веток.

## Requirements

### Requirement: Изменения хода

Система SHALL показывать под ответом, в котором агент правил файлы, строку «Изменения» с числом файлов и строк, а по нажатию — список файлов хода и дифф каждого файла (на телефоне — один столбец с переносом строк, без горизонтальной прокрутки) для всех трёх движков. (трекер: FEAT-18.8)

#### Scenario: Ход с правками

- **GIVEN** агент в ходе изменил два файла и создал один
- **WHEN** пользователь нажимает «Изменения · 3 файла» и выбирает файл
- **THEN** открывается дифф этого файла: добавленные строки со знаком «+», удалённые — со знаком «−»

#### Scenario: Ход без правок

- **GIVEN** ход только читал файлы
- **WHEN** ответ показан
- **THEN** строки «Изменения» нет

### Requirement: Git проекта

Система SHALL показывать для папки чата или проекта под git ветку, расхождение с upstream и изменённые файлы с диффом против последнего коммита и позволять закоммитить выбранные файлы с сообщением; автор коммита — из настроек пользователя. (трекер: FEAT-18.8)

#### Scenario: Коммит выбранных файлов

- **GIVEN** в репозитории изменены три файла
- **WHEN** пользователь отмечает два, пишет сообщение и нажимает «Коммит»
- **THEN** создаётся коммит ровно с этими двумя файлами и автором из Настроек → Git, третий файл остаётся изменённым

#### Scenario: Папка не под git

- **GIVEN** папка чата не является репозиторием
- **WHEN** пользователь открывает «Git»
- **THEN** экран говорит «Папка не под git», действий коммита нет

### Requirement: Предложение сообщения коммита

Система SHALL по кнопке «Предложить сообщение» отправлять отдельный короткий запрос к модели этого чата с диффом выбранных файлов и подставлять ответ в поле сообщения; запрос не попадает в историю чата. (трекер: FEAT-18.8)

#### Scenario: Сообщение от модели чата

- **GIVEN** Codex-чат и отмеченные файлы
- **WHEN** пользователь нажимает «Предложить сообщение»
- **THEN** в поле появляется сообщение от модели Codex этого чата, а в ленте чата нового хода нет

### Requirement: Отправка и права

Система SHALL разрешать отправку в удалённый репозиторий только администратору, когда в его Настройках → Git отправка разрешена, и показывать ошибки отправки понятным текстом; обычный пользователь работает с git только в папках своих чатов, без отправки и смены веток. (трекер: FEAT-18.8)

#### Scenario: Тенант пытается отправить

- **GIVEN** обычный пользователь в своём репозитории
- **WHEN** он вызывает отправку через API
- **THEN** сервер отвечает 403, а в интерфейсе кнопки «Отправить» нет

#### Scenario: Тенант и чужая папка

- **GIVEN** обычный пользователь
- **WHEN** он запрашивает статус git для папки вне своих чатов
- **THEN** сервер отвечает 403

#### Scenario: Нет доступа к удалённому репозиторию

- **GIVEN** у сервера нет доступа к origin
- **WHEN** администратор нажимает «Отправить»
- **THEN** показано «Отправка не прошла» с объяснением, коммиты остаются локально

### Requirement: Настройки Git

Система SHALL держать в Настройках раздел «Git» со значениями по умолчанию у каждого пользователя: автор коммитов (имя и почта), язык предлагаемого сообщения, отметка файлов по умолчанию; у администратора — разрешение отправки с сервера. (трекер: FEAT-18.8)

#### Scenario: Свой автор

- **GIVEN** пользователь задал в Настройках → Git имя и почту
- **WHEN** он делает коммит из портала
- **THEN** автор коммита — эти имя и почта
