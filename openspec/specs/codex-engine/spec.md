# codex-engine Specification

## Purpose
Третий движок портала: модели Codex (провайдер openai-codex, подписка ChatGPT владельца) обслуживает codex CLI через codex app-server и посредника lib/codex-shim.mjs, который говорит с раннером портала (lib/claude.js) на протоколе claude CLI. Capability описывает доступность и каталог Codex, ход, разрешения, режимы прав, Relay и ограничение «только admin» до настройки песочницы Codex на Windows (TASK-18.9).

## Requirements

### Requirement: Чат на Codex CLI

Система SHALL запускать ход чата с моделью провайдера `openai-codex` через `codex app-server` в папке чата и показывать ответ потоком, шаги хода (команды, правки файлов), файлы-результаты и расход; следующий ход продолжает тот же разговор Codex. (трекер: FEAT-18.7)

#### Scenario: Первый и второй ход

- **GIVEN** admin создал чат с моделью Codex
- **WHEN** он отправляет «меня зовут Алекс», а затем «как меня зовут?»
- **THEN** оба ответа приходят потоком, второй называет «Алекс», в ленте видны шаги и строка расхода с пометкой «подписка»

#### Scenario: Прерывание хода

- **GIVEN** идёт ход Codex
- **WHEN** пользователь нажимает «Стоп»
- **THEN** процесс Codex завершается, чат свободен для следующего сообщения

### Requirement: Разрешения Codex в чате

Система SHALL в режиме «Спрашивать» передавать запросы разрешений Codex (команда, правка файла) в чат тем же диалогом, что у других движков, с push «нужно ваше решение» и отметкой «Ждут вас», и отвечать Codex решением пользователя. (трекер: FEAT-18.7, FEAT-18.4)

#### Scenario: Разрешить запись

- **GIVEN** Codex-чат в режиме «Спрашивать»
- **WHEN** Codex просит записать файл и пользователь нажимает «Разрешить»
- **THEN** файл записан, ход продолжается

#### Scenario: Отклонить запись

- **GIVEN** Codex-чат в режиме «Спрашивать»
- **WHEN** пользователь нажимает «Отклонить»
- **THEN** файла нет, агент сообщает об отказе

### Requirement: Доступность движка Codex

Система SHALL предлагать модели Codex, только если codex CLI установлен и в нём выполнен вход; иначе портал работает как раньше и не показывает Codex. Codex доступен только admin: песочница Codex на Windows не настроена, разрешённая команда выполняется с правами сервера, поэтому тенанту движок codex не включается. (трекер: FEAT-18.7)

#### Scenario: Codex не установлен

- **GIVEN** на сервере нет codex CLI
- **WHEN** пользователь открывает выбор модели
- **THEN** группы Codex нет, чаты Claude и opencode работают как прежде

#### Scenario: Тенант и Codex

- **GIVEN** обычный пользователь (тенант)
- **WHEN** он создаёт чат с моделью Codex через API или admin пытается включить ему движок codex
- **THEN** сервер отвечает 403 на чат и 400 на включение, Codex не запускается, в каталоге тенанта Codex нет

### Requirement: Режимы прав в Codex-чате

Система SHALL предлагать в Codex-чате только режимы «Спрашивать» и «Без вопросов»; «Правки без вопросов» в Codex-чате отклоняются (400), а пришедшие с передачей чата выполняются как «Спрашивать» — без песочницы Codex молчаливый режим не может писать. (трекер: FEAT-18.7)

#### Scenario: Выбор режима

- **GIVEN** admin открыл выбор режима в Codex-чате
- **WHEN** список показан
- **THEN** в нём «Спрашивать» и «Без вопросов», «Правок без вопросов» нет

#### Scenario: Правки после передачи

- **GIVEN** Claude-чат в режиме «Правки без вопросов» передан Codex
- **WHEN** Codex хочет записать файл
- **THEN** запрос разрешения приходит в чат

### Requirement: Relay с Codex

Система SHALL передавать чат между Codex, Claude и opencode в обе стороны (ручной Relay и авто-Relay при лимите) с той же отметкой передачи и вложением пропущенных ходов. (трекер: FEAT-18.7, FEAT-11.18, FEAT-18.6)

#### Scenario: Передача Codex → Claude

- **GIVEN** Codex-чат, где пользователь назвал своё имя
- **WHEN** чат передан Claude и пользователь спрашивает «как меня зовут?»
- **THEN** Claude отвечает именем, в ленте отметка передачи

#### Scenario: Лимит Codex

- **GIVEN** авто-Relay включён и недельный лимит Codex исчерпан
- **WHEN** ход Codex падает по лимиту
- **THEN** ошибка распознана как лимит, чат передан первой доступной запасной модели
