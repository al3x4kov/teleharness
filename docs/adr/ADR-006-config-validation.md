# ADR-006. Единый конфиг с валидацией env

## Контекст

- 21 переменная окружения сервера читается в 8 модулях (server.js, auth,
  claude, file, mock, proxy, static, usage), плюс `ZAI_OUT_DIR` в build.mjs и
  6 переменных в edge. Полный список — architecture.md §5.
- Числа читаются как `Number(env ?? default)` без проверки. Опечатка в
  `ZAI_STALL_ABORT_MS` даёт `NaN`, а `NaN > 0` ложно — stall-abort тихо
  выключается. Похожий класс ошибок уже был в проде: опции watchdog'а молча
  терялись (инцидент 2026-11-01).
- `ZAI_UPSTREAM` читается дважды (server.js и proxy.js).
- В коде жёстко заданы `C:\Users\USER`, `D:\Portal`, `192.168.0.10`, путь к
  `claude.exe`, порт портала 4170 в edge.
- Эффективная конфигурация при старте не логируется: по логу нельзя
  понять, с какими таймаутами работал процесс.

## Решение

1. Модуль `lib/config.js` (zero-dep) — **единственное** место, где
   читается `process.env` на сервере. Экспортирует замороженный объект
   `config`.
2. Схема — таблица `{name, type: int|ms|bool|path|url|string|list, default,
   min?, max?, secret?}`. Правила:
   - `int/ms` — целое ≥ 0 (или в диапазоне); иначе ошибка;
   - `path` — абсолютный (`isAbsoluteDir`);
   - `url` — разбирается `new URL`;
   - `bool` — только `0/1`.
3. При невалидном значении процесс завершается с кодом 1 и сообщением
   «`ZAI_STALL_ABORT_MS`: ожидалось целое ≥ 0, получено `9oo000`».
4. При старте одна строка JSON `[zai-config] {...}` со всеми значениями и
   источником (`env`/`default`). Секреты (`ZAI_ADMIN_TOKEN`,
   `CLAUDE_CODE_OAUTH_TOKEN`) выводятся как `***`.
5. Новые переменные этого цикла объявляются здесь же: `ZAI_ENV`
   (ADR-003), `ZAI_ACCESS_LOG` (ADR-007), `ZAI_CLAUDE_IDLE_MS` (ADR-010).
6. 1.7: перенести в схему константы, которые сейчас зашиты в код (лимиты
   тела, TTL кэшей, ring, keepalive), с текущими значениями по умолчанию.
7. Edge (`ops/portal-server.js`) остаётся отдельным процессом без импорта
   `lib/`; в нём та же дисциплина (валидация и лог при старте), плюс
   `ZAI_EDGE_UPSTREAM` вместо жёсткого `127.0.0.1:4170`.

## Последствия

- Плюсы: опечатка в конфиге видна сразу и не выключает защиту молча; один
  источник правды для документации env; тесты могут создавать конфиг
  без манипуляций глобальным `process.env`.
- Минусы: fail-fast означает, что неверный env в задаче планировщика
  остановит портал; watchdog будет перезапускать его каждые 2 мин, пока
  конфиг не исправят. Это ожидаемо и видно в логе.
- Тесты (L1): таблица «значение → ок/ошибка»; секреты не попадают в лог.
- Миграция: значения по умолчанию совпадают с текущими, поведение прода
  не меняется.
