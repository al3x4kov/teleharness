# ADR-009. Edge выставляет x-forwarded-*; кука портала Secure и Path=/zai

## Контекст

- `handleLogin` ставит `Secure`, только если пришёл
  `x-forwarded-proto: https` (server.js:148–151). Edge этот заголовок не
  выставляет, а клиентский пропускает насквозь (portal-server.js:57).
  Итог: за :443 кука выдаётся без `Secure`, а клиент может подделать
  заголовок.
- Кука `Path=/`: браузер отправляет её на `/tv/*`, в TV API :8099 (edge
  проксирует все заголовки) и на статику `D:\Portal` в том же origin.
- Значение куки — сам долгоживущий токен (год), серверных сессий нет;
  logout токен не отзывает.
- IP клиента в портал не передаётся — журнал запросов (ADR-007) без него
  бесполезен для разбора инцидентов.

## Решение

1. **Edge** в `proxy()` для `/zai/*`:
   - удаляет клиентские `x-forwarded-proto`, `x-forwarded-for`,
     `x-forwarded-host`, `forwarded`;
   - выставляет `x-forwarded-proto: https|http` по листенеру,
     `x-forwarded-for: <req.socket.remoteAddress>`,
     `x-forwarded-host: <host>`.
   Для `/tv/api/*` — удаляет `cookie` и `authorization` портала (куку
   `ZAI_COOKIE_NAME`).
2. **Портал** доверяет `x-forwarded-*` только при соединении с 127.0.0.1
   (так и есть: слушает только loopback).
3. **Кука**: `Path=/zai`, `Secure` всегда, когда `x-forwarded-proto=https`
   (для `/zai` на :80 действует 308 на https, кроме `/zai/ca.pem`, поэтому
   http-случай остаётся только для прямого доступа к 127.0.0.1:4170 —
   тесты и стенд).
4. **Миграция**: при логине и в ответе `/auth/me` портал дополнительно
   отправляет `Set-Cookie: <name>=; Path=/; Max-Age=0`, чтобы снять старую
   куку. Через 30 дней эту строку можно убрать.
5. Перспектива (не в 1.6.2): серверные сессии — случайный sid в куке,
   отображение sid → userId в `data/sessions.json`, logout и смена токена
   отзывают sid (SEC-17, SEC-18).

## Последствия

- Плюсы: токен не уходит по http и в `/tv`; подделка `x-forwarded-proto`
  невозможна; IP клиента появляется в журнале; после этого можно включать
  проверку `Origin` (S23).
- Минусы: правка затрагивает и edge, и портал; edge перезапускается
  (задача `zai-portal`) только с согласия владельца; на переходный период
  у пользователя могут оказаться две куки — старая снимается п.4.
- Тесты: L3e — edge ставит/перезаписывает заголовки, вырезает куку для
  `/tv/api`; L3 — `Set-Cookie` содержит `Path=/zai` и `Secure` за https.
- Проверка на устройстве (L6): iPhone остаётся залогиненным после
  перехода, голосовой ввод работает.
