# AGENTS.md — точка входа для AI-агентов

**Teleharness** (кодовое имя `zai`) — мобильный веб-клиент (SPA) поверх агентных CLI: `opencode serve`
(любой провайдер opencode) и `claude` CLI. Интерфейс двуязычный (en/ru, `src/lib/i18n`); новые строки UI — только через словари.
Комментарии в коде — на русском или английском.

Прочитай по порядку, если задача больше одной правки:
1. этот файл;
2. [`README.md`](README.md) — возможности, установка, конфигурация;
3. [`docs/architecture.md`](docs/architecture.md) — модули, потоки данных, env;
4. [`openspec/specs/`](openspec/specs/) — требования по доменам (факт поведения системы).

## Карта

| Что | Где |
|---|---|
| Бэкенд (Node без runtime-зависимостей) | `server.js`, `lib/*.js`, `routes/*.js`; общий с клиентом код — `shared/` |
| Фронт (Preact + signals, esbuild) | `src/` → сборка `public/app.js`, `public/app.css` (`node build.mjs`) |
| Edge (TLS, маршрутизация `/zai/`) | `ops/portal-server.js` |
| Песочница тенантов, голос, рендер документов | `ops/sandbox/`, `ops/voice/`, `ops/render/` |
| Конфиги движков для портала | `ops/opencode/`, `ops/claude/` |
| Пользовательские конфиги Claude Code / opencode | `config/` (установка — `config/install.ps1`) |
| Тесты | `tests/*.test.js` (unit, сервер, edge), `tests/components/` (UI на happy-dom), раннер `tests/run-tests.mjs` |
| Фикстуры мок-режима | `fixtures/` (синтетические) |
| Спеки и ADR | `openspec/specs/`, `docs/adr/` |

## Порты по умолчанию

| Сервис | Порт |
|---|---|
| Портал | `127.0.0.1:4170` |
| Мок (`ZAI_MOCK=1`) | `4171` |
| Стенд (изолированный экземпляр) | `4172` + opencode `4097` |
| opencode serve 2.x | `127.0.0.1:4196` (`ops/opencode/serve-v2.sh` / `serve-v2.cmd`; порт 1.x `:4096` — история) |
| Edge | `:80` / `:443` |

## Правила

- **Секреты — только через переменные окружения** (`.env.example`). Ничего из `data/`, `secrets/`, `ops/certs/`
  не коммитить; токены, пароли и ключи в код, тесты и фикстуры не попадают.
- Любое изменение поведения — с тестом. `npm test` должен быть зелёным; серверные тесты гоняются последовательно
  (`--test-concurrency=1`): они поднимают реальные порты и дочерние процессы.
- Новые функции проверяются на обоих движках (opencode и claude CLI) и под не-admin тенантом.
- Требования фиксируются в `openspec/specs/<домен>/spec.md` (формат OpenSpec: `Requirement` + `Scenario`).
- Работающий экземпляр не перезапускать синхронно из чата самого портала — агент убьёт собственный процесс.
  Рестарт — отложенной задачей с проверкой `healthz` и откатом.
- Стенд и прод на одном хосте делят куки (куки не скоупятся по порту) — у стенда своё `ZAI_COOKIE_NAME`.
