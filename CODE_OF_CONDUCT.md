# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, no harassment or personal attacks.
Focus discussions on the code and the problem, not on people.

Unacceptable behaviour can be reported privately to the maintainer through
[GitHub](https://github.com/al3x4kov). Maintainers may remove comments, issues or contributions
that violate this code and may block repeat offenders.
